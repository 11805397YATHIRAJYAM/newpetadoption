Pet Adoption Platform:
A full-stack MERN application that connects pet shelters with people looking to adopt pets.
Users can browse pets, submit adoption requests, chat with shelters, manage favorites .

DEMO CREDENTIALS : 
1. USER :
              USERNAME: admin@petadopt.com
              PASSWORD : Password123!         ( note : P is CAPITAL)
2. SHELTER :
              USERNAME: shelter@petadopt.com
               PASSWORD : Password123!             ( note : P is CAPITAL)


Features :

### 👤 User Authentication
- Register & Login with JWT Authentication
- Secure Password Hashing
- Role-based Access (User, Shelter, Admin)

### 🐶 Pet Management
- View Available Pets
- Search & Filter Pets
- Pet Details Page
- Upload Multiple Pet Images
- Favorite Pets

### 📝 Adoption Application
- Apply for Pet Adoption
- Track Application Status
- Shelter Approval/Rejection

### 🏠 Shelter Dashboard
- Add/Edit/Delete Pets
- Manage Adoption Requests
- View Statistics

### 📅 Appointment Booking
- Schedule Shelter Visits
- Manage Appointment Requests

### ⭐ Reviews & Ratings
- Rate Shelters
- Leave Reviews
- View Community Feedback

### 🛡️ Admin Panel
- Manage Users
- Manage Shelters
- Manage Pets
- Platform Monitoring
